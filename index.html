Engagement Scanner

Clasificador de jugadores · segmentación para monetización

Modelo corriendo en tu navegador — ningún dato sale de este dispositivo

Este clasificador usa un árbol de decisión entrenado sobre el Predict Online Gaming Behavior Dataset (Kaggle, 40,034 jugadores) para predecir el nivel de engagement (Low / Medium / High) de un jugador a partir de su comportamiento, y lo cruza con un segmento de comportamiento (clustering) para sugerir una acción de monetización.
